## Executive Summary

Agentic AI systems — AI that can autonomously plan, use tools, and complete multi-step tasks — have emerged as one of the most transformative developments in artificial intelligence in 2025. Unlike traditional chatbots that respond to single prompts, agentic systems operate in loops, making decisions, taking actions, and adjusting based on results.

---

## 1. What is Agentic AI?

Agentic AI refers to systems where an AI model acts as an autonomous agent — breaking down complex goals into subtasks, calling external tools (search, code execution, APIs), observing results, and iterating until the task is complete.

Key characteristics:
- **Autonomy**: The agent decides *what to do next* without human prompting at each step
- **Tool use**: Agents call real-world tools — web browsers, databases, APIs, file systems
- **Memory**: Short-term (within a session) and long-term (across sessions) context retention
- **Planning**: Breaking a high-level goal into a sequence of achievable steps

## 2. Key Trends in 2025

### 2.1 Multi-Agent Frameworks
The industry has shifted from single-agent to multi-agent architectures. Systems now deploy specialized agents that collaborate — a researcher agent, a critic agent, a writer agent — each with distinct roles and tools.

### 2.2 Model Context Protocol (MCP)

### 2.3 Long-horizon task completion

## 5. Challenges and Open Problems

1. **Reliability**: Agents still fail on long-horizon tasks due to error accumulation
2. **Safety**: Autonomous action in the real world raises new alignment concerns
3. **Cost**: Agentic loops use significantly more tokens than single-turn interactions
4. **Evaluation**: Measuring agent performance on open-ended tasks is hard
