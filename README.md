# 🤖 Synthia — Autonomous AI Research Agent

> An agentic AI system built with the **Anthropic Claude API** that autonomously plans, searches the web, synthesizes findings, and generates structured research reports — without human intervention at each step.

---

## What This Is

AutoResearch is a **real AI agent** — not a chatbot. Given a research topic, it:

1. **Plans** — breaks the topic into focused sub-questions
2. **Acts** — calls web search tools autonomously
3. **Observes** — reads results and decides what to search next
4. **Synthesizes** — compiles findings into a structured markdown report
5. **Loops** — repeats until the research is complete

This is the core pattern behind modern AI agents: **Think → Act → Observe → Repeat.**

## Architecture

```
User Input (topic)
       │
       ▼
┌─────────────────────────────┐
│     Agent Core (Claude)     │  ← Anthropic API + Tool Use
│  Plans · Reasons · Decides  │
└────────────┬────────────────┘
             │ tool calls
    ┌────────┴────────┐
    ▼                 ▼
Web Search       Save Report
  Tool              Tool
    │                 │
    ▼                 ▼
DuckDuckGo      outputs/*.md
  Results
```

## Getting Started

### Prerequisites
- Python 3.10+
- Anthropic API key → [Get one here](https://console.anthropic.com)

### Installation

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/autoresearch-agent
cd autoresearch-agent

# Create virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Add your API key
echo "ANTHROPIC_API_KEY=your-key-here" > .env
```

### Run the Agent

```bash
python main.py
```
